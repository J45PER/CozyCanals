# Sprites

Every standing object in the game is a PNG in this folder, listed in
`sprites.json`. The current set is generated by `tools/make_sprites.js`
(`node tools/make_sprites.js`, needs Playwright), which overwrites these files.

## Replacing a sprite with your own image

1. Save your image as a PNG with a transparent background, using the same file
   name (for example `pub_a.png`).
2. If its size or position differs, edit its entry in `sprites.json`:
   - `w`, `h`: size on the map in game pixels at 1x zoom. A map cell is a
     72 x 36 diamond. The PNG itself can be any resolution; 3x is used here.
   - `ax`, `ay`: the anchor, measured from the top-left in the same units. It
     is the point that sits on the centre of the cell at ground level.
   - `smoke` (optional): where chimney smoke rises from, relative to the anchor.
3. Reopen the project in Godot so it re-imports the image.

## Naming

- Names end in a variant letter: `cottage_a`, `cottage_b`, ... The game picks a
  variant per map cell. Add `cottage_e.png` with a `sprites.json` entry to add
  another; no code changes are needed.
- Building stems: `cottage`, `terrace`, `shop`, `cafe`, `pub`, `boatyard`,
  `windmill`, `church`, `farm`, `manor`.
- Others: `oak`, `pine`, `poplar`, `willow`, `birch`, `bush`, `rock`, `sheep`,
  `cow`, `haybale`.
- Boats are `boat_<livery>_<heading>`: 16 headings (00 to 15) going round the
  compass in map space, for each livery.
